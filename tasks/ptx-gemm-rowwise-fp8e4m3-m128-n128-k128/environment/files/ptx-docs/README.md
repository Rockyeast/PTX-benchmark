# PTX ISA source record

This task targets PTX ISA 9.2 from CUDA 13.2.1, including FP8 conversion
instructions. The authoritative NVIDIA PTX ISA PDF is
https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf.

The NVIDIA PDF is not redistributed. This repository-authored record is mounted
read-only; online official PTX documentation is permitted.
