# PTX-Bench Task Catalog

This file lists only tasks included in an official PTX-Bench release. Development candidates,
feasibility probes, and calibration tasks are not part of the benchmark score.

## Released tasks

No task has been frozen for the first release yet.

## Non-scoring infrastructure

The repository may include smoke and calibration tasks for validating Harbor, Agent, PTX loading,
correctness, and timing. They are excluded from every published benchmark score.
