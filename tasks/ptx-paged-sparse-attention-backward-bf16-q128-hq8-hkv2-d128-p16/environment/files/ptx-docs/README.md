# PTX ISA source record

This task permits online access to NVIDIA's official PTX ISA documentation.
The NVIDIA PDF is not redistributed in this repository. This immutable record
identifies PTX ISA 9.2 for CUDA 13.2.1 and is hash-checked by the verifier.

Official source: https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf
