# PTX ISA source record

This task targets PTX ISA 9.2 from CUDA 13.2.1. The authoritative document is
the NVIDIA Parallel Thread Execution ISA 9.2 PDF:

https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf

The NVIDIA PDF is not redistributed in this repository. This source record is
provided read-only in the Agent environment; online access to official PTX
documentation is also allowed for the normal `online-docs` benchmark setting.
