# PTX ISA source record

This task targets PTX ISA 9.2 from CUDA 13.2.1. The authoritative NVIDIA
Parallel Thread Execution ISA PDF is available at:

https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf

The NVIDIA PDF is not redistributed here. This repository-authored source
record is mounted read-only, and the normal benchmark setting also permits
online access to official PTX documentation.
