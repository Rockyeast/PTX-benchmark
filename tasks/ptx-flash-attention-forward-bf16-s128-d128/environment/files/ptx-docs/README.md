# PTX ISA source for BF16 Flash Attention feasibility

The intended reference is NVIDIA Parallel Thread Execution ISA 9.2 from the
CUDA Toolkit 13.2.1 documentation archive:

https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf

The NVIDIA PDF is not redistributed in this development task. This README is
the hash-pinned runtime source record, not a substitute for an offline copy of
the ISA. A release that redistributes the PDF requires a separate license
review and updated trusted manifests.
