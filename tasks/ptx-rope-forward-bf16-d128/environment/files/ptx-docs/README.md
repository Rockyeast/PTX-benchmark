# PTX ISA source for RoPE feasibility

The intended reference is NVIDIA Parallel Thread Execution ISA 9.2 from the
CUDA Toolkit 13.2.1 documentation archive:

https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf

The NVIDIA PDF is not redistributed in this development task. This README is
the hash-pinned runtime source record; it is not a substitute for an offline
copy of the PTX ISA. A release that redistributes the PDF must first complete a
separate license review and then update both trusted manifests and their hash.
