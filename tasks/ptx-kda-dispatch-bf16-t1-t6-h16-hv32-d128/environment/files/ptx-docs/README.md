# PTX ISA source for fixed T6 speculative KDA decode

The intended reference is NVIDIA Parallel Thread Execution ISA 9.2 from CUDA
Toolkit 13.2.1:

https://docs.nvidia.com/cuda/archive/13.2.1/pdf/ptx_isa_9.2.pdf

The NVIDIA PDF is not redistributed. This hash-pinned repository-authored
source record is not a substitute for the ISA PDF.
